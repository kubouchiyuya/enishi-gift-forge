# ENISHI Gift Forge — ご縁ギフト設計室

セミナー参加者へ配布する「SNS事業者化 AIエージェント・スキルパック（中級者版）」です。

発信者・経営者・AI中級者が、自分の専門性を商品化し、協業提案を作り、7日間の小さな実験まで進めるために使います。

## 使い方

```text
/enishi-gift-forge
私の発信テーマと経験を、企業向けの協業商品に変えて。
専門性の棚卸し、対象顧客、提供価値、価格仮説、7日間の実験を作って。
```

目的別:

```text
発信を商品化して
協業提案を作って
企業向けのヒアリングシートを作って
7日間で検証できる実験にして
```

## 返るもの

- 専門性の棚卸し・差別化マップ
- 商品コンセプト・対象顧客・提供範囲
- 価格仮説と検証方法
- 協業提案書・ヒアリングシート
- 発信用の検証コンテンツ
- 7日間の実践スプリント
- 根拠・リスク・次の行動

## 5分スタートの入力

最初から完璧なプロフィールは不要です。次の4つだけ渡してください。

1. 何を発信しているか
2. どんな経験・実績があるか
3. 誰に何を提供したいか
4. 7日間で試せること

不明なものは `[TBD]` のまま扱います。
